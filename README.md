# 🎾 Grand Slam & World Tennis Tracker (テニストラッカー)

昔テニスを熱心に見ていた往年のテニスファンが、**「最近の選手が分からない」「四大大会（グランドスラム）や主要大会の経過・選手をもう一度追いかけたい」** という悩みを解決するために設計されたテニス情報ポータルです。

世界のトップ100位、日本のトップ20選手、車いすテニス（Open部門）トップ30選手のランキングと、近年の戦績・プレースタイルの特徴を分かりやすく一覧＆ポップアップ（モーダル）表示します。

---

## ✨ 主な機能

1. **豊富なカテゴリ対応**:
   - 👤 **男子シングルス (ATP)**: 世界トップ100位＋日本のトップ20選手
   - 👩 **女子シングルス (WTA)**: 世界トップ100位＋日本のトップ20選手
   - ♿ **車いすテニス (Open Division)**: 男子・女子・クァードの世界トップ30選手（小田凱人、上地結衣等）
   - 👥 **ダブルス (ATP / WTA)**: 世界の頂点および日本のスペシャリスト（マクラクラン勉、青山修子、柴原瑛菜、加藤未唯等）
   - 🏆 **四大大会 (グランドスラム)**: 全豪・全仏・ウィンブルドン・全米の特徴・サーフェス・近年の歴代優勝者一覧

2. **往年のテニスファン向け選手ポップアップ解説**:
   - 選手をクリックすると詳細情報がスムーズにモーダル表示されます。
   - **ESCキー**、**背景クリック**、**×ボタン** のいずれでも快適に閉じることができます。
   - キーボードの `←` `→` や画面内のボタンで、前後の選手へ連続移動可能。
   - 「往年の名選手（フェデラー、ナダル、ジョコビッチ、錦織圭など）との比較」や「どんなテニスをする選手か」が直感的にわかる見どころガイド付き。

3. **快適な絞り込み＆検索**:
   - 🇯🇵 **「日本勢トップ」ワンクリックフィルター**: 日本人選手（トップ20等）を即座に抽出。
   - 🔍 **リアルタイム検索**: 漢字・ひらがな・カタカナ・英語表記・国名に対応。
   - 📊 **表示モード切替**: リッチな「カード表示」と情報一覧「テーブル表示」をワンタップ切替。

4. **二段階データストレージ設計 (Firebase / Local JSON)**:
   - **アカウント作成前**: 同梱の最新ローカルJSONデータから自動で動作（設定不要）。
   - **アカウント作成後**: Firebase Firestoreの設定を入力するだけで、クラウドDB連携へ自動昇格。

## 🚀 ローカルでの動作確認

Node.js等のインストールは不要です。Mac標準のPythonで即座にブラウザ確認できます：

```bash
# ターミナルで本ディレクトリに移動後
python3 -m http.server 3000
```

ブラウザで `http://localhost:3000` を開きます。

## ⚡ Vercelでの公開手順 (数分で完了)

1. [Vercel](https://vercel.com/) にアクセスし、GitHubアカウントでログイン。
2. 「**Add New...**」→「**Project**」をクリック。
3. 先ほどプッシュした `tennis-tracker` リポジトリを選択して「**Import**」。
4. Framework Preset は「**Other**」のままで、特別なビルドコマンドは不要です。
5. 「**Deploy**」ボタンをクリック。
6. 数秒で世界中に高速配信される独自URL（`https://tennis-tracker-xxxx.vercel.app`）が発行されます！

## 🔥 Firebase（Firestore）アカウント連携手順 (後から設定する場合)

Firebaseアカウントを後で作る際のステップです：

1. [Firebase Console](https://console.firebase.google.com/) にアクセスし、新しいプロジェクトを作成（例: `tennis-tracker`）。
2. 左メニュー「**構築**」→「**Firestore Database**」を選び、「**データベースの作成**」をクリック（テストモードで開始）。
3. プロジェクト概要の歯車アイコン「**プロジェクトの設定**」→「**全般**」タブ下部の「アプリを追加」から「**ウェブ (</>)**」を選択。
4. 表示される `firebaseConfig` オブジェクトの各キー（`apiKey`, `projectId`, 等）をコピー。
5. 本アプリ（画面右上の「⚙️ Firebase設定・管理」ボタン）を開き、各項目を貼り付けて「**設定を保存して接続テスト**」をクリック。
6. 下部の「**🚀 現在のデータをFirestoreに一括保存 (シード)**」を押すと、現在表示されている全選手・大会データがFirestoreへ一括アップロードされます。

## ✏️ 選手データの更新・追加方法

時々ランキングや戦績を更新したい場合、以下の2つの方法があります：

### 方法A: 管理画面から更新（おすすめ）
ブラウザで `/admin/index.html`（ローカルなら `http://localhost:3000/admin/index.html`）を開きます。
- 選手一覧から対象選手を選び、順位や戦績、解説を編集して「保存」。
- 「新規選手を追加」から新たな注目若手選手を登録可能。
- 「JSONダウンロード」を押してダウンロードしたファイルを `data/` フォルダに上書きし、GitHubにコミット＆プッシュするとVercel側も自動更新されます。

### 方法B: Pythonスクリプトで一括生成・更新
`scripts/generate_initial_data.py` のリストを編集し、以下を実行：
```bash
python3 scripts/generate_initial_data.py
```
`data/*.json` が自動更新されます。
